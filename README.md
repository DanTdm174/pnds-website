# pnds-website

Website for the Pacific Northwest Debate Society (PNDS).

Static site, no build step. Pages: `index.html`, `mission.html`, `team.html`, `services.html`, `get-involved.html`. Shared styles in `styles.css`, menu script in `site.js`, images in `assets/`.

Open `index.html` in a browser to preview.

Design rules: blue and white palette, 8px spacing scale, one border radius (8px), one shadow style, Fraunces (headings) and Source Sans 3 (body). When you change `styles.css`, bump the `?v=` number in each page's stylesheet link so browsers load the new version.
