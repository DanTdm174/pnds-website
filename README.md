# pnds-website

Website for the Pacific Northwest Debate Society (PNDS).

Static site, no build step: `index.html`, `styles.css`, and `assets/`.
Open `index.html` in a browser to preview.

Design rules: blue and white palette, 8px spacing scale, one border radius (8px), one shadow style, Fraunces (headings) and Source Sans 3 (body).
